LAYOUT

o modo simples nao ficou muito bom
no modo simples deve contar os seguintes itens
separados em 3 linhas

linha 1 status
informacoes do que o app esta fazendo atualmente como state ip do server ou do client dependendo do modo iniciado porta tcp e last mensagem

linha 2 server
um botao de start/stop indicando se quer iniciar o servico de transmissao ou desligar

linha 3 client
deve haver um campo para o usuario digitar o ip do server ao qual deseja se conectar e um botao de start/stop de estados e textos alternados para se ligar ou desligar ao server selecioando e iniciar a reproducao 








DOCS


apos fazer as mudancas atualiza e documentacao e marque nos arquivos de planejamento o que ja foi feito




se na mesma pasta do exetuvavel houver um arquivo chamado shareaudio.cfg
ele deve ser usado para tomada de decisão imediata ao abrir o gui ou o cli
ou seja dentro do arquivo podem haver as seguintes variaveis 

AUTOSTART
SERVER_IP
SHARE_QUALITY
DEVICE_ID

O ESSAS VARIAVIES NAO SAO OBRIGATORIAS MAS SE EXISTIREM COMPLETE OS CAMPOS AUTOMATICAMENTE AO INCIAR GUI OU USE AS CASO O CLIENTE NAO USE ARGUMENTOS PARA O CLI 
MAS A VARIAVEL AUTOSTART É FUNDAMENTAL E DEVE SER A CHAVE QUE ATIVA OU DESATIVA O USO DE TODAS AS OUTRAS USE UMA SKILL DE BRAINSTORM PARA PENSAR COMO DEVE FUNCIONAR OS BENEFICIOS E OS PROBLEMAS DESSA NOVA FEATURA , ME FAÇA PERGUNTAS PRA FECHAR O PLANO TOTALMENTE ANTES DE INICIR A EXECUÇÃO
